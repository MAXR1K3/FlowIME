# FlowIME P7.1 — light-theme refinement

P7.1 continues the P7 presentation-layer work without changing the automation engine, providers, rule resolution, persistence, or foreground watcher.

## Changes

- Light mode now uses a warm beige surface palette:
  - app background `#F5F0E6`
  - primary cards `#FCFAF5`
  - inset surfaces `#EFE8DC`
  - warm neutral card stroke `#DDD4C7`
- Dark mode keeps a neutral Windows-style dark presentation and continues to follow the system theme.
- The shell background is theme-aware; NavigationView stays transparent so the light beige surface remains visually continuous.
- The Input Method Support page no longer exposes Provider implementation/status details such as `ConversionMode` or `OpenStatus`.
- The support page now only communicates information that affects user decisions: which input methods can be selected in rules, and that more providers may be added later.

## Core-logic boundary

No changes were made to `FlowIME.Core`, `FlowIME.Windows`, `FlowIME.Infrastructure`, `FlowIME.Probe`, or `FlowIME.App/Services`.
