## 冻结边界

后续改动必须保持：

1. 应用规则始终优先于全局默认。
2. 全局默认不允许 `Keep`；应用规则允许 `Keep/Chinese/English`。
3. UI 中的选择值必须来自 `ActionOptions` 的实际选项对象，不能退回不稳定的枚举 `SelectedValue` 绑定。
4. “已决策”不能等同于“已应用”；只有目标线程/profile/mode 验证通过才能记录 `Applied`。
5. 诊断和游戏文本输入继续遵守隐私边界：不读取输入内容、剪贴板内容、URL、窗口正文或游戏内存。

## 尚未关闭的运行时问题

- 高频前台/焦点事件产生较多 `cancelled`，当前尚未证明是功能错误，但需要保留可观测性。
